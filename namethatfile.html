How to use NameThatFile

  1. Drop PDFs, images or folders onto NameThatFile.
  2. Review the suggested names; broad photo subjects and general names are used when there is no clear title.
  3. Click Rename Files, then use Undo This Batch or Batch History if needed.

Batch rename without moving your files

Drop files or folders into the app, review the suggested names, then rename the batch. Each file stays in its existing folder with the same extension and contents.

Read document text and scanned pages

PDF text and on-device optical character recognition help find a useful heading. Up to the first six PDF pages are checked. When a subject is unclear, the app can use a general name based on the file type, dimensions or page count.

Keep Undo after closing the app

Undo This Batch restores original names. Batch History keeps earlier batches available after you quit. Before undoing, the app checks that each file is still the same and skips files that have changed.

Handle duplicate names safely

Existing files are never overwritten. Conflicting names receive a numbered suffix, such as “Invoice (2).pdf”. Unsupported, unavailable and corrupt files are reported or skipped.

Questions about NameThatFile

Does NameThatFile upload my documents?

No. File analysis happens on your computer. Your documents, images and extracted text are not uploaded to Minyapps or an online AI service.

Will it always recognize the subject of a photo?

No. Recognition is a helpful suggestion, not a guarantee. Review names before renaming. Unclear subjects receive a general name rather than an invented title.

How does the Windows edition recognize images?

Windows uses a bundled image model and Windows text recognition. Mac uses Apple’s on-device Vision and PDFKit frameworks. Recognition results can differ between platforms.
