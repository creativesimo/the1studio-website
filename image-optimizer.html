How to use Image Optimizer

  1. Drop images or a folder into Image Optimizer.
  2. Pick a quality preset and Auto or a specific format. Use Preview to compare the output.
  3. Click Optimize Images and collect the copies from the Optimized folder.

Compare suitable formats automatically

Auto compares supported encoded candidates and chooses an output for each image. Text and graphics can favor lossless WebP or PNG. You can also choose WebP, JPEG, PNG or AVIF yourself when available.

Preview the actual output

The comparison preview uses the encoded result, so you can inspect quality against the original before exporting. Quality settings are codec controls, not a promise of identical appearance or a measured similarity score.

Export responsive images and HTML

Choose additional smaller widths to create responsive image variants. The app can generate a starter HTML snippet using the actual saved names. Adjust sizes and write meaningful alt text for your website.

Keep control of output quality and size

Optional settings include a maximum edge, a KB target, a minimum quality and a filename suffix. A KB target does not silently reduce dimensions or cross the selected quality floor. Originals remain unchanged.

Questions about Image Optimizer

Does AVIF work on every Mac?

AVIF export is available only when the current macOS provides an AVIF encoder. The Windows edition includes its own AVIF encoder. WebP is bundled on both platforms.

Will the output always be smaller?

No. The result depends on the source, format, quality and selected transforms. An explicitly requested conversion can be larger. Results reports the actual size; preview helps you choose a suitable setting.

Does it preserve animation or HDR?

No. The app handles still images and exports 8-bit SDR copies. Animated and multipage inputs are excluded rather than silently flattened. HDR and gain-map data are not retained.
